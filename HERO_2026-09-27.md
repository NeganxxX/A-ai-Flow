# Açaí Flow — banner integrado (27/09/2026)

- Nova arte de referência integrada sem duplicar a tipografia dentro do banner.
- O lado textual continua em HTML para manter links, acessibilidade e responsividade.
- A área visual usa recortes específicos desktop/mobile da nova arte.
- A rotação de tons já existente foi preservada; agora também aplica ajustes suaves de filtro na arte.
- As animações orgânicas/frutas existentes foram preservadas de forma mais discreta para não competir com a foto.
- Breakpoints tratados para desktop, tablet e mobile.

## Versão final — arte como fundo (27/09/2026)
- A arte inteira (produto + fundo) agora é o **fundo da seção** (`.hero-bg`), sem imagem separada flutuando. Textos, botões e localização continuam em HTML por cima.
- Arquivos: `img/banners/hero-bg-desktop.webp` (arte sem texto, com extensão no topo para cobrir qualquer largura) e `img/banners/hero-bg-mobile.webp` (composição vertical para tablet/celular, ≤1000px).
- Troca de cores: `js/script.js` continua alternando `flow-tone-0..4` a cada 5s; o CSS aplica uma camada de cor (`.hero-tint`, poupando a área do produto) + leve ajuste de filtro no fundo. `flow-tone-0` mostra a arte original.
- Mantidas: frutas animadas e formas orgânicas (discretas), entrada suave do texto, deriva lenta do fundo, `prefers-reduced-motion`.
- `responsivo.css` não controla mais o hero (os conflitos antigos foram removidos); todo o CSS do banner está no fim de `css/style.css`.
- Para trocar a arte no futuro: substitua os dois `.webp` mantendo os nomes.
